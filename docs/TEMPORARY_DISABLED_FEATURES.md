# Current limitations

| Capability | Today |
|---|---|
| CV1 recording | A single CV1 press starts or ends a session. The home screen keeps the original Omi buttons. |
| Mute | Temporarily silences audio within a recording. |
| Phone microphone | Started by the original "+" button; the local capture controller requires the Omi to be disconnected. |
| Text during a conversation | Experimental [live preview](LIVE_PREVIEW.md), a separate Mac process; the screen opens by tapping the recording card. Draft quality is still under evaluation. |
| Speaker separation | In the current setup all text belongs to a single speaker. |
| Recording without the Mac link, uploading later | Not wired up yet. |
| Omi online features | Disabled in local mode. |

Press the CV1 button once to start a recording and once more to end it.
A single press ends the session even while muted. In the phone app the
button on the card temporarily mutes and unmutes the audio.
The browser can view, play, and delete recordings.

The CV1 can record quietly. Switching sources sometimes creates short
extra files. Recording integrity across connection drops is not yet
guaranteed.
